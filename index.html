지식관리

사업장별 문서를 모아 검색하고, 현황 수치가 어느 문단에서 나왔는지 원문으로 확인합니다. 변경 제안과 승인 이력이 남습니다.

로컬 실행 — 공개 주소 없음 보안 검토 전이라 외부에 열지 않았습니다. 작동하지 않는 링크를 만들지 않으려고 여기에는 주소를 두지 않습니다.
화면 수치는 간이 추정이며 최종 업무판단은 사용자가 수행합니다.
각 도구 상단의 「개선안」 버튼을 누르면 메일 앱이 열립니다 — 어느 화면이었는지는 자동으로 붙고, 입력하신 숫자는 보내지 않습니다.
